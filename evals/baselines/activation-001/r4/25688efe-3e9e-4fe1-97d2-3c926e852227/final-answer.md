# 竞品主张审阅：C1

**主张 C1**：Zcode 已支持导出会话记录。
**材料 M1**：《Zcode 功能说明（合成摘录）》，合成发布日期 2026-10-20；摘录：“Zcode 新增会话记录导出，工作区管理员可在会话页面发起导出。”

审阅仅基于上述提供材料，未做重新调查。

## 一、按证据清单逐项核对

1. **实体与产品范围匹配**：M1 中的“Zcode”与主张实体一致，产品对象“会话记录导出”也对应。这一点上没有明显错配。
2. **时间线区分**：
   - M1 只有一个**合成发布日期 2026-10-20**。发布日期本身不能证明该功能的实际上线时间，也不能证明“现在”（审阅时点）仍然可用。摘录中无检索时间记录。
   - 摘录用词“**新增**”属于材料原文措辞，只能作为引述保留，不能据此推断功能在 2026-10-20 前后某个时间上线。**该功能的上线/可用时间在材料中缺失，应保留为“未知”**。
3. **材料性质（来源可信度）**：M1 标题和说明均明确其为“合成摘录”，属于本用例合成内容，不能证明 Zcode 真实存在该功能或发布过该公告。因此它至多是“待审阅的材料”，而不是经过验证的事实依据。
4. **矛盾与缺失来源**：材料只有一份，无矛盾证据；也无官方/一手来源可交叉验证。
5. **其他**：不涉及 MCP 结果。

## 二、材料实际能支持的范围

- 作为**合成材料的引述内容**，M1 陈述了：Zcode 有“会话记录导出”能力，且**由工作区管理员在会话页面发起导出**。
- 主张 C1 的核心指向（存在“导出会话记录”功能）在材料字面上有对应表述，但存在两点范围差异：
  - **主体范围收窄**：材料限定为“工作区管理员可在会话页面发起”，C1 表述为“Zcode 已支持导出会话记录”，未体现管理员角色和入口限制，比材料更宽。
  - **时效无依据**：C1 的“已支持”暗含当前可用，材料无法证明当前状态（无检索时点、无持续可用性证据）。

## 三、还缺什么依据

1. **真实、 preferably 一手/官方来源**：如官方更新日志、帮助文档、发布公告，以替代或佐证这份合成摘录。
2. **功能上线/可用的事件日期**：材料仅有合成发布日期，缺实际上线时间；该日期应保持“未知”，不能用 2026-10-20 或其前后推断。
3. **当前可用性证据**：带检索时间的实际产品界面、文档或可复现的验证记录，以支持“已支持/仍可用”的表述。
4. **权限与范围细节**：导出是否仅限工作区管理员、是否支持其他角色、可导出的会话范围、导出格式与限制等。
5. 若要把 C1 放宽为“面向所有用户的导出能力”，还需非管理员角色同样可导出的证据。

## 四、结论

- **可支持的结论**：仅能说“一份合成摘录材料声称 Zcode 新增会话记录导出，并称工作区管理员可在会话页面发起导出”；该材料的来源为合成，发布日期为 2026-10-20（合成），功能实际上线时间未知，当前可用性未经验证。
- **不支持的结论**：不能宣称 Zcode 真实、已上线并在当前时点支持导出会话记录；不能推断上线时间在 2026-10-20 前后；不能将“新增”转述为确切的发布事件。
- **待补充**：官方/一手来源、带日期的功能可用性证据、检索时点，以及管理员权限范围之外的导出能力证据（如主张需覆盖更广用户群）。
