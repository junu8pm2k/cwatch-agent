# Case 7：相互冲突的材料

场景：核心逻辑。设计 ID：`core-005`，revision 1。目的：隔离无法由现有信息消解的冲突，不以排列顺序决定可信度。

## Prompt

请审阅 C1，保留 M1、M2 各自的说法，说明能否据此形成确定结论，以及需要什么补充信息。以下均为合成材料，不联网。

C1：deepseekharness 企业套餐的工作区管理员可以导出会话记录。

M1：同一产品、同一套餐、同一管理员角色的说明称“允许导出会话记录”。

M2：同一产品、同一套餐、同一管理员角色的另一份说明称“不提供会话记录导出”。

两份材料都没有版本、生效日期或可用于判断优先级的来源信息。
