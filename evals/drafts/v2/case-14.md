# Case 14：JSON 交付契约

场景：产物质量。设计 ID：`artifact-002`，revision 1。目的：使用与 Case 13 相同的已核对事实，隔离机器可读交付问题；主要可由代码验证，不因是 Agent eval 就强制使用 LLM。

## Prompt

请将下面已核对的合成结果转换为一个 JSON 对象。直接输出 JSON，不加 Markdown 代码围栏或前后解释，不调用工具、不联网、不生成文件，不新增事实。

已给结果：
- 主张标识：C1。
- 材料标识：M1。
- M1 的内容：Zcode 会话记录仅由工作区管理员从会话页面发起导出。
- 现有主张“所有成员均可导出”扩大了角色范围。
- 材料未说明导出格式与记录时间范围。

对象只包含以下字段：
- claimId：字符串，保留给定主张标识。
- materialIds：字符串数组，保留给定材料标识。
- role：字符串，填写材料中的角色。
- entry：字符串，填写材料中的入口。
- exportFormats：未知时必须为 null，不用空数组或猜测格式代替未知。
- recordTimeRange：未知时必须为 null。
- issue：字符串，概括已给出的主张问题。
