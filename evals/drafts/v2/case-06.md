# Case 6：保留来源性质

场景：核心逻辑。设计 ID：`core-004`，revision 1。目的：检查用户给定的来源关系，不要求访问现实网站验证品牌。

## Prompt

请核对 C1 中关于证据来源的说法。只使用下列合成来源记录，说明它们能支持什么、还缺什么，不联网。

C1：kimicode 已获官方确认支持会话导出，而且有两份独立来源交叉验证。

M1：用户手工编写的合成摘录，标题为《kimicode 官方功能公告》，正文称支持会话导出；没有实际公告链接或认证记录。

M2：同一用户将 M1 原文复制到另一份笔记，标题改为《会话导出介绍》。本用例明确记录 M2 的内容来自 M1。
