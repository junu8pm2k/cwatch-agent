# Research Brief

Answer a scoped research question using identifiable source material.

## Establish the question

Identify the subject, time range, requested comparison, and intended output. Use the user's supplied material first when it covers the request; ask only for essential missing scope.

## Gather and compare sources

1. Inspect the tools actually available in this run. For public web research, use `web_search` to find candidate sources and `web_fetch` to read their contents when those tools are disclosed. Read a source guide before its API tool when required.
2. Compare the retrieved sources. Separate direct observations, interpretations, and unresolved points. Prefer original material for factual claims and retain meaningful contradictions.
3. Distinguish publication time from retrieval time. A snippet or failed request is insufficient evidence for a factual conclusion; retain the gap when the source cannot be inspected.

## Deliver the brief

Write a direct answer, the findings needed to support it, source links or supplied-document references, and material limitations. Match the detail to the user's question. Save a file only when requested and permitted by the host.

Do not invent tool results, cite unread material as verified, or claim unavailable tools were used. This Skill supplies a procedure; it does not register tools or grant execution permissions.
